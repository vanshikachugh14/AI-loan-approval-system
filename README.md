# AI Loan Approval System

An AI-powered loan approval system built using Flask, SQLite, SQLAlchemy, and Machine Learning.

## Features
- Loan approval prediction
- Approval probability score
- Applicant management (CRUD)
- Search applicants
- Dashboard analytics
- PDF report generation
- Loan approval charts

## Technologies Used
- Python
- Flask
- SQLite
- SQLAlchemy
- Scikit-learn
- Bootstrap
- Chart.js
